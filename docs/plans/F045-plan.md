# F045 konten-beranda-blok — Mesin blok bersama dan beranda berbasis blok

Status rencana: APPROVED (keputusan orkestrator setelah revisi 1, 2026-10-17; revisi 2 pemangkasan YAGNI tanpa review ulang)

## Ringkasan & tujuan
Paket 2 audit (`docs/audits/ui-ux-portal-konten.md` §2.2–2.3, §3.4, §5.3, S2, C1, C3, C5, C8, §9). Beranda F036 (field hero, keunggulan, media, ringkasan halaman `profil`, section otomatis tetap di kode) diganti **daftar blok** yang disusun admin dengan Filament Builder. Mesin blok (simpan, baca, validasi, sanitasi teks, pemilih tujuan tombol) dipakai juga oleh footer widget di F046; area `footer` ditambahkan di F046, bukan disiapkan di sini.

## Ruang lingkup
- Termasuk: mesin blok bersama; 7 tipe blok beranda; halaman admin Beranda (Builder); render Blade per blok; migrasi field F036 + `portal.archived_footer_quote`; data demo beranda (cukup isi `DemoData`; demo lama diulang dengan `migrate:fresh --seed`); teks bantuan tanpa basmalah/sapaan (C8); `docs/erd.md`, `docs/prd.md` §beranda, `docs/design-guide.md` §6 (latar blok Ajakan).
- Tidak termasuk (eksplisit): footer widget (F046); blok "Info PSB ringkas" (ditunda ke revisi F038, butuh status gelombang + biaya); tanda "unggulan" berita/album dan ringkasan halaman (S4); ikon media sosial; tema/warna dari admin (S7); blok di halaman statis; blok Angka (`stats`); ikon keunggulan; posisi gambar kiri/kanan; filter kategori dan jumlah item feed; saklar badge PSB dan "Lihat semua"; kode perbaikan data demo lama.

## Model data
**Keputusan user (17 Okt 2026, via orkestrator):** Q1–Q4 diterima dengan usulan default; termasuk Q2 (hero migrasi dua tombol Daftar + Berita) dan Q3 (kutipan arsip F043 tampil sebagai blok terakhir), serta perubahan kecil tercatat: ringkasan profil menjadi salinan statis, video profil/PSB bertumpuk, video PSB tidak ikut saklar PSB.

Tanpa perubahan skema tabel. Key settings baru `portal.home_blocks` (JSON), dibaca lewat `GetSchoolProfile::KEYS` (tetap satu query). Tidak ada = tanpa blok.

Blok = `{type, visible: bool, data}`; maks. 20 blok; `hero` maks. 1. Item tombol = Item navigasi F043 tanpa `group` (`{type, label ≤30, page_id?, category_id?, url?}`).

| type | data (batas) | Tidak dirender bila |
|---|---|---|
| `hero` | `eyebrow` ≤100, `title` ≤150 (kosong → nama lembaga), `text` ≤300 polos, `image` path + `image_alt` ≤150 **atau** `album_id`, `primary`/`secondary` ?Item; badge PSB otomatis saat gelombang dibuka | `visible=false` |
| `text_image` | `heading` ≤100 opsional, `text` teks terbatas ≤2000, `image`+`image_alt` (satu tata letak: gambar kanan di ≥1024px, di atas teks di seluler), `button` ?Item | heading, teks, dan gambar kosong |
| `features` | `heading` ≤100 opsional, `items` 1–8 `{title ≤80, text ≤300 polos}` | — |
| `quote` | `text` ≤1000 wajib, `translation` ≤1000, `source` ≤100, `rtl` bool | — |
| `cta` (Ajakan) | `eyebrow` ≤60, `heading` ≤100 wajib, `text` ≤300 polos, `primary`/`secondary` ?Item, `variant` light/navy/gold | — |
| `video` | `heading` opsional, `video_id` wajib (hanya ada bila video ada) | video hilang / modul konten mati |
| `feed` | `source` posts/achievements/albums/videos, `heading` opsional (kosong → label `lang/id` per sumber); jumlah item tetap per sumber di kode (posts 6, achievements 3, albums 4, videos 3); "Lihat semua" selalu tampil bila ada item | 0 item / modul konten mati |

Batas data = batas field F036/F043 asalnya (`hero_greeting` 100, `highlights_heading` 100, kutipan 1000/1000/100), jadi hasil migrasi selalu lolos validasi tanpa dipangkas. `image_alt` wajib bila `image` terisi; `image` dan `album_id` hero tidak boleh bersamaan.

Teks terbatas = HTML hanya `<p>`, `<br>`, `<strong>`, `<a href>`; lainnya dibuang. **Aturan URL aman** (href teks terbatas dan `url` Item tombol, satu fungsi bersama): setelah trim, diterima hanya `https?://` (tak peka huruf besar) atau path yang diawali tepat satu `/` (bukan `//`, bukan `/\`); karakter kontrol/spasi di skema → ditolak. Tautan luar dipaksa `rel="noopener noreferrer"`. Teks polos di-escape, baris baru dipertahankan. Judul seksi selalu `h2`; judul hero `h1`.

**Migrasi** `database/migrations/2026_10_20_000000_move_portal_home_to_blocks.php` (pola F043: `DB::table`, JSON di-decode sendiri, nilai rusak = kosong, satu transaksi, logika lama disalin, tidak memanggil kelas aplikasi):
- Lewati bila `portal.home_blocks` sudah ada (idempotent). **Instalasi lama** = tabel `settings`, `pages`, `posts`, `albums`, atau `videos` punya baris; instalasi baru (semua kosong) → tidak menulis apa pun.
- Instalasi lama → blok berurutan sama dengan tampilan sekarang: `hero` (eyebrow = `hero_greeting`, title = `hero_title`, text = `hero_subtitle` ?? `school.tagline`, `album_id` = `hero_album_id`, primary `psb.register`, secondary `posts`); `features` bila `highlights` berisi; `video` untuk `profile_video_id` lalu `psb_video_id` (yang terisi); `text_image` dari halaman `profil` terbit yang ringkasannya (strip tag, rapatkan spasi, 300 karakter) tidak kosong: heading = judul halaman, text = ringkasan ber-`<p>` ter-escape, button `{type: page, page_id}`; `feed` posts, achievements, videos, albums (heading null); `quote` dari `archived_footer_quote` (arabic → text + `rtl` true; tanpa arabic → translation menjadi text, `rtl` false).
- Blok `video` hanya dibuat bila baris `videos` dengan id itu ada; `album_id` hero hanya disalin bila album ada.
- Key lama dihapus **hanya bila migrasi menulis blok** (bila `home_blocks` sudah ada, key lama dibiarkan). Hapus key lama: `portal.hero_greeting|hero_title|hero_subtitle|highlights_heading|highlights|hero_album_id|profile_video_id|psb_video_id`, `portal.archived_footer_quote`.
- `down()` sederhana: hanya menghapus `portal.home_blocks`; isi key lama **tidak dipulihkan** (dicatat di docblock migrasi); berkas gambar tidak dihapus.

## Action class
- `app/Actions/Konten/ParseContentBlocks` (baru) — `handle(string $area, mixed $stored): list<Block>`; katalog tipe per area (F045 hanya `home`); blok rusak, tipe tak dikenal, atau tipe bukan milik area dibuang per item; `visible=false` dibuang untuk portal (opsi `withHidden` untuk form). **Sanitasi saat baca:** setiap field teks terbatas melewati `SanitizeBlockText`, setiap `url` Item tombol diperiksa aturan URL aman (tidak aman → item dibuang), field polos dipaksa string. Portal tidak pernah merender JSON settings tanpa lewat Action ini.
- `app/Actions/Konten/NormalizeContentBlocks` (baru) — validasi penuh area + batas per tipe, satu galat membatalkan semua; field galat `home_blocks.{i}.data.{field}` (bersarang `...items.{j}.title`, `...primary.url`); rujukan `page_id`/`category_id` (Item tombol)/`album_id`/`video_id` harus ada; Item tombol divalidasi dengan aturan `UpdatePortalNavigation` (logika item dipindah ke trait bersama `Concerns/ValidatesNavigationItems`).
- `app/Actions/Konten/SanitizeBlockText` (baru) — sanitasi teks terbatas (whitelist di atas, berbasis symfony html-sanitizer yang sudah dipakai `SanitizeContentHtml`).
- `app/Actions/Konten/UpdatePortalHome` (ditulis ulang) — input `{home_blocks}` + actor. Gambar: `UploadedFile` → `StorePublicImage` (JPG/PNG, 2 MB) di `portal/blocks`; path string hanya diterima bila sudah ada di `portal.home_blocks` tersimpan (`image_invalid`); path yang tidak dipakai lagi dihapus setelah commit (`ReplacesStoredFiles`). Log `portal_home_updated` hanya bila berubah.
- `app/Actions/Konten/GetPortalHomeData` (ditulis ulang) — output `{school, blocks: list<RenderBlock>, hasHero}`. Rujukan dimuat per jenis sekali: album+foto (maks. 10 foto), video, gelombang PSB terbuka (sekali), Item tombol **dari semua blok dikumpulkan lalu diselesaikan dalam satu panggilan** `GetPortalNavigation::resolveItems()`; `feed` satu query per blok dengan jumlah tetap per sumber. Modul konten mati → tabel konten tidak di-query. `psb.register` di blok beranda dan badge PSB hero hanya tampil saat ada gelombang terbuka (perilaku beranda sekarang).
- `app/Actions/Konten/GetPortalNavigation` (diubah) — method publik `resolveItems(array $lists, ?int $labelMax)`: resolusi tautan bersama (aturan ketersediaan, label fallback, batch query yang sama).
- `app/Actions/Konten/GetSchoolProfile` (diubah) — `KEYS` tanpa key lama, tambah `portal.home_blocks`; output `home_blocks` mentah untuk `ParseContentBlocks`; hapus `hero`, `highlights*`, `*_album_id`, `*_video_id`.

## UI (Filament / Blade)
- `app/Filament/Pages/Site/Home.php`: satu `Builder` `home_blocks` (tambah, seret urutan, hapus dengan konfirmasi bawaan, ciutkan; label blok dari heading/judul). Tiap blok punya Toggle "Tampilkan" (simpan ↔ `visible`). Field Item tombol memakai komponen pemilih tujuan yang dipindah dari `Navigation` ke `app/Filament/Pages/Site/Concerns/LinkTargetFields.php` (Navigation ikut memakainya, perilaku tetap). Teks terbatas: `RichEditor` toolbar `bold`, `link` saja. Gambar: `FileUpload` `storeFiles(false)` seperti Identitas. Rujukan yang sudah hilang dikosongkan saat form diisi; untuk `video_id` wajib, galat menyebut bahwa blok harus dihapus atau diisi video lain. Galat dipetakan lewat `SettingsFormPage::stateField` (indeks → UUID Builder).
- Teks bantuan (C8): contoh judul hero "Pendidikan berasrama untuk putra jenjang SMP dan SMA"; tanpa basmalah, salam, atau sapaan.
- Blade: `resources/views/portal/home.blade.php` iterasi blok → `resources/views/portal/blocks/{type}.blade.php`. Tanpa hero → pita sederhana `h1` nama lembaga (+ slogan Identitas bila ada). Hero: dua kolom ≥1024px (teks kiri, media kanan), media di atas teks di 360px, slider album di dalam kolom (tidak melewati lebar layar), nama Arab tidak dirender otomatis (C3). `feed`: judul + "Lihat semua" (C5) ke `/berita`, `/berita?jenis=prestasi`, `/galeri`, `/video`. Grid adaptif (C1) sederhana untuk `features` dan `feed`: kolom `lg` = min(jumlah item, maks.), baris sisa di tengah (`flex flex-wrap justify-center` atau setara); kelas literal ditulis utuh (bukan interpolasi). Komponen `x-portal.adaptive-grid` hanya bila dipakai ≥2 view blok; bila tidak, cukup markup di view. Ajakan: light = latar band, navy = `bg-primary-950` teks putih fokus `ring-accent-400`, gold = `bg-accent-500` teks `primary-950`. Kutipan rtl: `lang="ar" dir="rtl"` + `font-arabic`. Band `gray-50`/putih tetap memakai `$band()`, hanya untuk blok yang dirender.
- Teks `lang/id/pondok.php` (`school_profile.blocks.*`, `portal.home.*`). Design guide §0, §2 (emas bukan teks), §6, §10.

## Permission & cakupan
Tidak ada permission baru. Halaman Beranda tetap `view:school-profile` (super-admin, admin-sekolah, admin-konten). Tanpa `unit_user`. Blok `video`/`feed`/album hero mengikuti `modules.konten.enabled`; tombol mengikuti aturan ketersediaan navigasi.

## Kriteria penerimaan (bisa dites)
- **AC-1** Migrasi instalasi lama (seluruh key F036 + halaman `profil` terbit + arsip kutipan) → `portal.home_blocks` berisi hero (dua tombol `psb.register` + `posts`), features, video, video, text_image, feed ×4, quote (`visible` true) dengan isi dan urutan sesuai aturan; key lama terhapus; jalan kedua tanpa perubahan; `home_blocks` yang sudah ada tidak ditimpa dan key lama tidak dihapus. Urutan seksi sama dengan beranda lama, **kecuali** perubahan yang disetujui user: tombol kedua hero, kutipan tampil, profil salinan statis, video bertumpuk. Nilai di batas lama (`hero_greeting` 100, `highlights_heading` 100, kutipan 1000) dimigrasi utuh dan blok hasil migrasi lolos `NormalizeContentBlocks` tanpa diubah. Video/album yang sudah dihapus tidak menghasilkan rujukan.
- **AC-2** Migrasi pada DB kosong tidak membuat `portal.home_blocks`; instance yang pernah disemai (`SettingSeeder` mengisi `school.name`/`modules.*`) dianggap instalasi lama dan mendapat hero + feed ×4 meski tanpa field beranda (sama dengan tampilan sebelum migrasi); `down()` hanya menghapus `portal.home_blocks`.
- **AC-3** Simpan valid: setiap tipe blok (termasuk Item tombol tiap tujuan, teks terbatas, gambar unggahan) tersimpan ternormalisasi sesuai urutan; satu log `portal_home_updated`; simpan ulang tanpa perubahan tanpa log.
- **AC-4** Simpan tidak valid → `ValidationException` di field bersarang yang tepat dan settings tidak berubah: tipe tak dikenal, hero kedua, > 20 blok, item di luar batas (features 0/9), field wajib kosong, panjang lebih, rujukan halaman/kategori/album/video tidak ada, `variant`/`source` tak dikenal, URL tombol tidak aman (`javascript:`, ` JavaScript:`, `//host`, `data:`), `image` + `album_id` bersamaan, `image` tanpa `image_alt`, path gambar yang bukan milik beranda, unggahan non-JPG/PNG atau > 2 MB.
- **AC-5** Sanitasi: teks terbatas hanya menyisakan `p`, `br`, `strong`, `a[href]`; `<h1>`, `<script>`, `style`, `class`, `onclick`, href `javascript:`/`//host` dibuang; tautan luar ber-`rel="noopener noreferrer"`; teks polos dan heading di-escape. **Saat baca:** nilai berbahaya yang ditulis langsung ke `settings` (`<script>` di teks terbatas, `javascript:` dan `//evil.test` di href dan `url` tombol, `<img onerror>` di heading/judul) tidak muncul sebagai markup aktif di HTML `/`.
- **AC-6** Gambar: unggahan baru tersimpan di disk `public`; mengganti atau menghapus blok bergambar menghapus berkas lama setelah simpan berhasil; simpan gagal tidak meninggalkan berkas baru.
- **AC-7** Render: blok tampil sesuai urutan; `visible=false`, blok kosong, video/album hilang, feed 0 item, dan blok konten saat modul konten mati tidak dirender tanpa error; tepat satu `h1`; judul seksi `h2`; DB tanpa blok → hanya pita `h1` nama lembaga dan footer.
- **AC-8** Hero: label kecil, judul (fallback nama lembaga), teks, gambar dengan `alt` atau slider album; tombol memakai label/tujuan tersimpan dan tujuan tak tersedia tidak dirender; `psb.register` dan badge PSB (otomatis, tanpa saklar) hanya saat gelombang dibuka; `school.arabic_name` terisi tetapi tidak muncul di beranda.
- **AC-9** Ajakan dan Kutipan: tiga varian merender kelas latar token yang benar tanpa `text-accent-*`; kutipan rtl ber-`dir="rtl" lang="ar"`, terjemahan dan sumber opsional tidak dirender bila kosong.
- **AC-10** Feed: tiap sumber menampilkan item terbaru dengan jumlah tetap (posts 6 tanpa prestasi, achievements 3, videos 3 unggulan, albums 4 berfoto), judul fallback dari `lang/id`, "Lihat semua" selalu tampil bila ada item, menuju URL yang benar dengan `aria-label`.
- **AC-11** Grid adaptif: kolom `lg` = min(jumlah item, maks.) (mis. features 2 item → 2 kolom, 5 item maks. 4 → 4 kolom dengan baris sisa di tengah); 1 item tidak memakai grid lebar penuh.
- **AC-12** Query: menambah blok statis (text_image, features, quote, cta bertombol halaman) tidak menambah jumlah query beranda (satu assert perbandingan jumlah query).
- **AC-13** Admin Beranda: render untuk super-admin, admin-sekolah, admin-konten dan 403 untuk peran lain; form terisi dari settings (rujukan hilang dikosongkan); tambah, urutkan, sembunyikan, hapus blok lalu simpan memanggil Action; galat bersarang tampil di field blok yang benar; teks bantuan `school_profile.blocks.*` tidak memuat "Bismillah", "Ahlan", atau "Assalamu".
- **AC-14** Tanpa konten bawaan & demo: instalasi baru tanpa DemoSeeder tidak punya blok dan tidak menampilkan teks konten; DemoSeeder (dua kali, idempotent) mengisi beranda contoh fiktif dari `DemoData` dengan semua tipe blok (kutipan QS. Ali 'Imran: 104, tanpa basmalah/sapaan). Tidak ada kode perbaikan data demo lama.

## Risiko & pertanyaan terbuka
- Q1–Q4 sudah diputuskan user (lihat Model data).
- **Q1 (diputuskan: ya):** tombol `psb.register` di blok beranda hanya tampil saat gelombang dibuka (seperti beranda sekarang), sedangkan tombol header tetap mengikuti modul PSB. Usulan: ya.
- **Q2 (diputuskan: diterima):** hasil migrasi hero mendapat dua tombol (Daftar + Berita); saat pendaftaran dibuka beranda menampilkan dua tombol, bukan satu seperti sekarang. Usulan: diterima, admin bisa menghapus tombol kedua.
- **Q3 (diputuskan: tampil):** kutipan arsip F043 dimigrasi sebagai blok terakhir dan langsung **tampil** di beranda. Alternatif: disimpan tersembunyi. Usulan: tampil.
- **Q4 (diputuskan: ya):** blok "Info PSB ringkas" (§5.3) tidak masuk F045 dan dibahas bersama revisi F038. Usulan: ya.
- Ringkasan halaman `profil` menjadi salinan statis di blok Teks + gambar (tidak ikut berubah bila halaman diedit) sampai S4 menambah field ringkasan.
- Video profil dan PSB menjadi dua blok bertumpuk (bukan dua kolom); video PSB tidak lagi ikut saklar modul PSB.
- Judul demo "Selayang Pandangan" hanya ada di DB lokal; `DemoData` sudah "Selayang Pandang", jadi cukup `migrate:fresh --seed`.
- Ditunda sebagai catatan (bukan dikerjakan): blok Angka, ikon keunggulan, posisi gambar, filter kategori/jumlah feed. Bila user meminta, jadi entri baru di `feature_list.json`.
- Catatan implementasi (minor review): Paket A/B/C dikerjakan sebagai pemanggilan green-coder terpisah dengan laporan masing-masing.
- Builder + FileUpload bersarang: pastikan `storeFiles(false)` bekerja di dalam blok Builder Filament 5 (cek dokumentasi saat implementasi).
