# F105 konten-tema-css-font — Tema membawa CSS dan font sendiri

Issue: #142
Status rencana: APPROVED bersyarat (revisi 1, Review #1), menunggu jawaban user atas pertanyaan terbuka
PR ditujukan ke `dev` (cabang `feat/f105-tema-css`), memakai `Refs #142`, bukan `Closes`. Jalur penuh (skema, keamanan, penyimpanan, route baru).

**Syarat sebelum RED:** butir yang bertentangan dengan teks issue (penyajian lewat route vs disk `public`, `data:` di CSP, tema ber-CSS mengalahkan setelan admin) dan pilihan validator CSS (tulis sendiri vs dependensi) ADALAH USULAN yang menunggu keputusan user (Pertanyaan 1, 2, 4, 6). Desainnya ditulis lengkap di bawah agar bisa langsung dipakai bila disetujui; bila user memilih lain, bagian terkait direvisi.

## Ringkasan & tujuan
Tema resmi bertanda tangan boleh membawa `theme.css` dan font `woff2` sendiri agar identitas visualnya berbeda (warna, huruf, bentuk, pola, border, bayangan). Tanpa JavaScript dari tema. Tema tanpa CSS berperilaku persis seperti sekarang (golden `default`/`centered` hijau). CSS/font hilang atau rusak = tampilan inti (HTTP 200, `Log::warning`).

## Ruang lingkup
- Termasuk: kunci `assets` di skema, `ValidateThemePackage` (bersama untuk pasang dan `pondok:theme-sign`), validator CSS/font/kontras/gerak, penyimpanan + pasang multi-berkas + Rollback/Remove, route aset, `<link>` + `data-pt-theme`, kontrak markup `data-pt*` + `docs/tema-kontrak-markup.md`, `pondok:theme-sign` untuk folder (+`--write-hashes`), `docs/rilis.md`, `docs/design-guide.md`, `lang/id`.
- Tidak termasuk: JavaScript dari tema; perilaku komponen (kartu balik, ticker/pita agenda umum, timeline) = F106; keempat tema mockup dan aset pada tema bawaan `resources/themes` = F107 (tema uji F105 = fixture di tests dengan woff2 palsu bermagic `wOF2`; mockup tidak disalin); check doctor hash penuh tema terpasang (ditunda); tema pihak luar; builder; preload font; `scroll-behavior` pada `html` (CSS terkurung di scope `body`); kode perbaikan data demo.

## Keputusan desain
1. **Format paket, aditif.** `schema_version` tetap 1, `CORE_VERSION` 1.1.0 -> 1.2.0; tema ber-assets menulis `min_core` 1.2.0 (tanpa aturan khusus; inti lama menolak `assets` sebagai kunci tak dikenal, pola F104). Kunci puncak opsional `assets` (set kunci tertutup): `css` = `{path:"theme.css", sha256, size}`; `fonts` = maks. 6 `{path:"fonts/<nama>.woff2", family, weight, style, license:OFL-1.1|Apache-2.0|CC0-1.0, sha256, size}`; `contrast` = daftar `{fg:"--var", bg:"--var", size:normal|large}`, >= 1 bila `css` ada. Path regex `^theme\.css$` dan `^fonts/[a-z0-9][a-z0-9-]{0,40}\.woff2$`, unik. Tanda tangan tetap atas byte `theme.json`; sha256 per berkas di manifest mengikat semuanya. Entri katalog F103 TIDAK berubah. `ValidatePortalTheme` hanya memeriksa skema dan menambah kunci `assets` ke keluaran HANYA bila ada (tema lama: keluaran identik, test lama tak pecah); pemeriksaan berkas ada di `ValidateThemePackage`.
2. **Batas (satu set konsisten):** manifest 64 KB; CSS 128 KB; font <= 250 KB/berkas (6 x 250 KB = 1,5 MB); total paket (manifest + CSS + font) <= 1,5 MB.
3. **Unduh.** Job: manifest -> sha/size/tanda tangan (kode F103) -> `ValidatePortalTheme` -> tiap berkas dari direktori `entry.url` + path manifest lewat `ThemeCatalogClient` yang sama (https, host sama, 443, redirect terbatas, streaming; batas per berkas = min(size terdeklarasi, batas tipe)) ke `_staging/<slug>` -> sha256 + size -> `ValidateThemePackage` -> pasang. Tenggat total dihitung di job (150 dtk; sisa waktu menjadi timeout tiap unduhan), `$timeout` job 180 dtk; lewat tenggat = `failed`. Tanpa `assets` = perilaku F103 persis.
4. **Penyimpanan** hanya akar terpasang `storage/app/themes/<slug>/`: `theme.json`, `previous.json`, `assets/<hash12>/{theme.css,fonts/*}`; `hash12` = 12 hex pertama sha256 byte manifest. Pasang: dir `assets/<hash12>` yang sudah ada dan bukan milik `theme.json`/`previous.json` aktif dihapus lalu diganti (pemasangan ulang setelah gagal di tengah); tulis dir baru -> ganti `theme.json` atomik (mekanisme F103) -> pangkas dir selain milik `theme.json` dan `previous.json`. Invarian F103 diperluas: dir aset milik `theme.json` aktif SELALU lengkap. Rollback memvalidasi `previous.json` lewat staging, memeriksa dir asetnya (ada + size cocok; kalau tidak, ditolak tanpa perubahan), lalu memangkas dir selain milik `theme.json` baru. Remove menghapus semua.
5. **Penyajian (USULAN, Pertanyaan 1)** lewat route `GET /tema/{slug}/{hash12}/{path}` (nama `theme-asset`, di luar grup `portal.`): `withoutMiddleware($statelessWeb)` (tanpa sesi/cookie/CSRF), `EnsureModuleIsEnabled:konten,404`, `SetPortalSecurityHeaders`, bukan `SetPortalCacheHeaders` (md5 isi tak cocok untuk berkas). Controller `Portal/ShowThemeAsset` memanggil `ResolveThemeAssetPath`: slug/hash12/path diregex dulu; slug harus berupa tema terpasang (aktif dipilih atau tidak tetap dilayani); hash12 = hash `theme.json` terpasang; path terdaftar di manifest; `realpath` harus berawalan dir `assets/<hash12>` dan bukan symlink; selain itu 404 TANPA `Cache-Control` immutable. Header 200: `Content-Type` tepat (`text/css; charset=utf-8`, `font/woff2`), `nosniff`, `Cache-Control: public, max-age=31536000, immutable`, ETag/304. Alasan dibanding disk `public`: tanpa symlink, aman terhadap `PUBLIC_STORAGE_ROOT` dan `PUBLIC_DISK_DRIVER=s3`, same-origin (font tanpa CORS; `url()` relatif jatuh ke path yang sama), tipe/path dibatasi di satu tempat. Cadangan HTML <= 5 menit yang menunjuk hash lama (sudah dipangkas) mendapat 404 CSS sementara: tampilan inti, diterima.
6. **Tautan.** `layouts/public`, hanya bila `$themed` dan tema aktif ber-`assets.css` lolos `CheckThemeAssetsRuntime` (berkas ada + size cocok; sha penuh hanya saat pasang/sign): `<link rel="stylesheet" href>` RELATIF (`route('theme-asset', ..., absolute: false)`, karena route aset di luar `ForcePortalRootUrl` dan HTML di-cache publik) setelah `@vite` dan `<style data-portal-theme>`, serta `<body data-pt-theme="<slug>">`. Pemeriksaan runtime di `ResolveActiveTheme`; gagal = tema dianggap rusak pada render itu (fallback F102, `Log::warning` sekali per slug); `ListPortalThemes` menampilkan `valid=false` + alasan. Panel admin tak pernah memuat CSS tema.
7. **Interaksi Tailwind.** Utilitas Tailwind 4 di `@layer`; CSS tema tanpa layer selalu menang tanpa perang spesifisitas. Markup inti tetap. Ditolak: varian markup semantik kedua (menggandakan view) dan pembungkusan `@layer` di server (mengubah byte ber-hash). Risiko: tema harus menimpa properti eksplisit termasuk varian responsif utilitas (mis. `md:grid-cols-*` butuh `@media` sendiri); dijelaskan di dokumen.
8. **Kontrak markup.** Tema menarget kait stabil, bukan kelas utilitas. Hanya pada tema ber-css (golden tak berubah) tiap node mendapat `data-pt="<komponen>"`, `data-pt-variant` bila ada, `data-pt-part` untuk bagian bernama, status lewat `aria-current`/`aria-expanded`; akar `<header>`/`<footer>` lewat tag. Atribut dibuat satu helper yang mengembalikan string dengan spasi pendahulu bila tema ber-css dan string kosong tanpa spasi bila tidak (tak ada perubahan byte). Sumber tunggal `ThemeComponents::PARTS` (komponen -> bagian); tabel di `docs/tema-kontrak-markup.md`, dijaga test.
9. **Validator CSS (tulis sendiri, nol dependensi, ALLOWLIST; USULAN, Pertanyaan 2).** Tokenizer sadar komentar dan string, case-insensitive, FAIL-CLOSED (galat PCRE atau tokenizer apa pun = tolak). Tolak backslash di mana pun (termasuk dalam string) dan NUL. Daftar selektor dipisah hanya pada koma tingkat atas (bukan di dalam `:is()`/`:not()`/string atribut); tiap selektor harus diawali bentuk kanonik tunggal `body[data-pt-theme="<slug>"]` (dibandingkan sebagai token, bukan substring), tanpa `:root`/`html`/`*`/`body` telanjang dan tanpa kelas atau id; hanya tipe, atribut (`[data-*]`, `[aria-*]`, `[lang]`, `[dir]`), pseudo, kombinator. Tolak nesting (`&`, blok di dalam blok; `@media`/`@supports` satu tingkat berisi aturan datar). At-rule allowlist: `@media`, `@supports`, `@keyframes` (nama `pt-*`), `@font-face`. Fungsi: allowlist sebagai mekanisme (var, calc, min/max/clamp, warna, gradient, transform, easing, bentuk dasar, counter, attr non-url, filter dasar); semua yang di luar daftar ditolak. `url()` hanya di properti allowlist (i) `@font-face src` ke path `assets.fonts` dengan `format("woff2")`, (ii) `data:image/svg+xml,` terenkode-persen pada `background*`/`mask*`/`-webkit-mask*`/`border-image-source`, <= 4 KB per URI dan 16 KB total; TIDAK di custom property, prelude `@media`/`@supports`, atau properti lain. Isi SVG ditolak bila memuat `<script`, `<foreignObject`, `<image`, `<use`, `<style`, `href`, `url(` non-fragmen, atau `on*=`. Daftar tolak (data uji, bukan mekanisme): `expression(`, `behavior`, `-moz-binding`, `javascript:`/`vbscript:`, `image-set`, `src()`, `element()`, `cursor:url`, `list-style-image`, `content:url`, `local()`, `!important`, family yang menimpa font inti. Custom property hanya pada scope tema. Batas: <= 128 KB, <= 2000 aturan, kurung seimbang, UTF-8 sah.
10. **Font** (method `ValidateThemePackage`): magic `wOF2`, sha/size cocok, `@font-face` wajib `font-display: swap`, `font-family` = `family` manifest, `src` hanya `url(<path manifest>) format("woff2")`, tanpa CDN; setiap font manifest dirujuk `@font-face` dan sebaliknya.
11. **Kontras** (method `ValidateThemePackage`): pasangan `assets.contrast` merujuk custom property bernilai literal `#rrggbb` yang didefinisikan TEPAT SEKALI di blok scope tema tingkat atas `theme.css` (definisi ganda/tak ada/bukan hex = galat); dihitung `BuildColorScale::contrast`: >= 4,5:1 `normal`, >= 3:1 `large`. **Jaminan hanya untuk pasangan terdeklarasi** (keputusan user; sisanya tanggung jawab penerbit), dicatat di dokumen. Lint gerak: `animation*`, `transition*`, `scroll-behavior` selain `none`/`0s`/`auto` hanya di dalam `@media (prefers-reduced-motion: no-preference)`.
12. **Prioritas token (USULAN, Pertanyaan 4).** Tema ber-css menang atas warna/font admin F070 karena `theme.css` datang setelah `<style data-portal-theme>`; token inti tetap tersedia sebagai `var()`; tema ber-`contrast` memakai hex sendiri. Satu catatan di Situs > Tampilan.
13. **CSP (USULAN, Pertanyaan 6).** `img-src 'self' https: http:` memblokir `data:` sehingga pola SVG/mask mockup tak tampil. Usulan: tambah `data:` ke `img-src` untuk SEMUA respons portal (global, diterima: SVG sebagai gambar tak menjalankan skrip; `script-src 'self'` tetap). `font-src 'self'` sudah cukup. Test CSP disesuaikan.
14. **Keamanan:** replay seperti F103 (versi harus lebih tinggi) + aturan validator mengetat bersama `CORE_VERSION`; traversal ditutup regex path + nama tetap + `is_link` + `realpath`; tanpa zip; kebocoran lewat CSS tertutup (tanpa `url()` eksternal/`@import`). Risiko sisa diterima: kunci bocor + CSS penuh dapat menimpa UI; mitigasi `k2` dan tinjauan sebelum menandatangani.
15. **Cakupan:** hanya route `portal.*` (kecuali sitemap/robots) dan `psb.info`; cache portal ±5 menit tak berubah.

## Kriteria penerimaan
- **AC-1** Skema `assets`: manifest sah lolos; tanpa `assets` keluaran sama (tanpa kunci `assets`) dan golden tak berubah; ditolak: kunci asing, path luar regex/ganda, > 6 font, license di luar allowlist, sha256 bukan 64 hex, size di atas batas (font 250 KB, CSS 128 KB, total 1,5 MB), `css` tanpa `contrast`; `CORE_VERSION` 1.2.0 (`min_core` 1.3.0 ditolak).
- **AC-2** Integritas: satu byte berubah di manifest (tanda tangan), `theme.css`, atau font menolak paket tanpa mengubah tema terpasang; size beda, berkas hilang/berlebih, bukan `wOF2`, dan symlink ditolak.
- **AC-3** Validator CSS menolak SETIAP pola (dataset Pest, satu test per pola): daftar tolak butir 9, backslash di mana pun, `url()` di custom property/prelude `@media`/properti non-allowlist, nesting (`&`, blok dalam blok), koma di dalam `:is()`/`:not()`/string atribut yang menyelundupkan selektor tanpa awalan, awalan scope yang hanya mirip (substring/huruf besar/spasi), fungsi di luar allowlist, `@keyframes` tanpa `pt-`, SVG berbahaya, batas ukuran/aturan/URI/UTF-8, dan input besar pemicu backtrack PCRE (hasil: ditolak, bukan lolos atau exception).
- **AC-4** CSS sah representatif mockup lolos: custom property pada scope, SVG data-URI, `mask-image`, `clip-path: polygon`, radius elips, bayangan keras, `@keyframes pt-*` + `prefers-reduced-motion: no-preference`, `@font-face`.
- **AC-5** Font: tanpa `font-display: swap`, family beda dari manifest, `src` luar/`local()`, font tak dirujuk atau `@font-face` tanpa font manifest, dan menimpa font inti ditolak.
- **AC-6** Lint gerak: `animation`/`transition`/`scroll-behavior` aktif di luar `prefers-reduced-motion: no-preference` ditolak; di dalamnya atau `none`/`0s` lolos.
- **AC-7** Kontras: pasangan >= batas lolos; di bawah (4,5 normal, 3 large), variabel tak ada, bukan hex literal, atau didefinisikan ganda ditolak dengan pesan menyebut pasangan dan rasio.
- **AC-8** Pasang/Rollback/Remove atomik: sukses menulis `assets/<hash12>/` lalu `theme.json` dan memangkas dir lain; dir `<hash12>` sisa pemasangan gagal dihapus lalu diganti saat pasang ulang; kegagalan disimulasi di tiap langkah menjaga invarian (dir aset `theme.json` aktif lengkap, `previous.json` utuh atau tak ada, tanpa sisa staging); Rollback mengembalikan manifest + aset, memangkas dir selain milik `theme.json`, dan menolak bila dir aset `previous.json` hilang; Remove menghapus semua; tanpa `assets` = perilaku F103.
- **AC-9** Job: URL berkas dari direktori `entry.url`; host/skema/redirect/batas per berkas dan total lewat `ThemeCatalogClient`; sha256/size salah, berkas 404, dan lewat tenggat total memberi `failed` berpesan Indonesia tanpa mengubah tema lama; entri katalog tak berubah.
- **AC-10** Route aset (stateless lewat `$statelessWeb`): 200 dengan `Content-Type` tepat, `nosniff`, `immutable`, ETag/304, tanpa `Set-Cookie`; slug non-aktif tetap dilayani; 404 (tanpa `immutable`) untuk slug/hash12/path tak dikenal, traversal, path di luar manifest, symlink/realpath di luar dir aset, dan modul Konten mati.
- **AC-11** Render: tema ber-css memuat `<link href>` relatif setelah `@vite` dan `<style data-portal-theme>`, `data-pt-theme` pada body, `Cache-Control` public + ETag, tanpa `csrf-token`, aset Livewire, `Set-Cookie`; tema tanpa css byte-identik golden `default`/`centered`, dijalankan untuk setiap komponen dan varian; panel admin tak memuat CSS tema.
- **AC-12** Fallback: `theme.css`/font hilang atau size beda saat render memberi HTTP 200 dengan chrome inti dan `Log::warning` sekali per slug; `ListPortalThemes` `valid=false` + alasan.
- **AC-13** Kontrak markup: test melintasi `ThemeComponents` x varian memastikan `data-pt`, `data-pt-variant`, dan semua `data-pt-part` dari `PARTS` ada pada tema ber-css dan tidak ada tanpa css (tanpa spasi sisa); `docs/tema-kontrak-markup.md` memuat setiap komponen, varian, bagian.
- **AC-14** `pondok:theme-sign <folder>` menjalankan `ValidateThemePackage` yang sama dan gagal (exit 1, pesan jelas) tiap pelanggaran; hash tak cocok mencetak nilai benar, `--write-hashes` menulis ulang hash sebelum menandatangani; keluaran entri sama dengan F103 dan deterministik.
- **AC-15** `img-src` CSP memuat `data:` (bila Pertanyaan 6 disetujui); teks lewat `lang/id` (`theme_assets.*`, catatan Tampilan); `ModuleComplianceTest` lulus; `docs/rilis.md` ("Menyusun, menguji, dan menandatangani paket tema ber-CSS") dan `docs/design-guide.md` (satu paragraf) diperbarui.

## Risiko & pertanyaan terbuka (butuh keputusan user)
Risiko: kunci bocor (butir 14); kontras hanya untuk pasangan terdeklarasi; menimpa utilitas responsif butuh disiplin penerbit; 404 CSS sementara setelah pembaruan; tanpa pratinjau sebelum pasang.
1. **Penyajian** lewat route (usulan, butir 5) atau berkas statis di disk `public` sesuai teks issue (butuh symlink/`PUBLIC_STORAGE_ROOT`, tak cocok S3). Butuh jawaban sebelum RED; menyimpang dari issue.
2. **Validator CSS** tulis sendiri dengan allowlist (usulan) atau dependensi parser (butuh persetujuan).
3. **Batas ukuran** (butir 2) cukup untuk mockup? Usulan: ya.
4. **Tema ber-CSS mengalahkan setelan admin** (usulan, butir 12) atau admin tetap menang. Menyimpang dari F104; butuh jawaban.
5. **Selektor kelas/id dilarang dan semua selektor berawalan scope tema** (usulan): mengikat tema ke kontrak `data-pt`.
6. **CSP `img-src` + `data:` global** (usulan, butir 13) atau pola latar hanya dari gradient CSS. Butuh jawaban sebelum RED.
